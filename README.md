# 🩺 PCOS Detection in Women  

Polycystic Ovary Syndrome (PCOS) is a common hormonal disorder that can lead to serious health complications if not detected early.  

This project presents an **AI-powered system** for early and accurate detection of PCOS using a **multimodal deep learning approach**.

---

## 📌 Overview  

The system combines **ultrasound image analysis** and **clinical/hormonal data** to improve prediction accuracy.

- 🖼️ **CNN (Convolutional Neural Network)** is used for analyzing ultrasound images  
- 📊 **Machine Learning models** process clinical data such as:  
  - Age  
  - BMI  
  - Insulin levels  
  - Hormone levels  

The outputs from both models are **fused together** to generate a final prediction.

---

## 🎯 Objectives  

- Detect PCOS at an early stage  
- Improve diagnostic accuracy using AI  
- Combine multiple data sources (multimodal learning)  
- Assist healthcare professionals in decision-making  

---

## 🚀 Features  

- Multimodal learning (Image + Clinical Data)  
- Deep Learning-based image classification (CNN)  
- Machine Learning models for structured data  
- Improved prediction accuracy using model fusion  
- Data preprocessing and feature selection  
- Visualization and analysis of medical data
