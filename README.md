# PCOS-Detection-in-Women
Polycystic Ovary Syndrome (PCOS) is a common hormonal disorder that can lead to serious health issues if not detected early. This project presents an AI-based system for early and accurate detection of PCOS using a multimodal deep learning approach.

The system combines two types of data: ovarian ultrasound images and clinical/hormonal parameters. A Convolutional Neural Network (CNN) is used for image-based analysis, while machine learning models process clinical data such as age, BMI, insulin levels, and hormone levels.

The outputs from both models are fused to generate a final prediction, improving overall accuracy and reliability. This approach aims to assist healthcare professionals in better and faster diagnosis of PCOS.
